# Automatic Number Plate Recognition (ANPR) System

## 📌 Project Overview

The Automatic Number Plate Recognition (ANPR) System is a computer vision-based project developed to automatically detect and recognize vehicle number plates from images.

The system uses image processing, object detection, and Optical Character Recognition (OCR) techniques to identify the number plate and extract the characters from it.

## 🎯 Objectives

- Detect vehicle number plates from images.
- Extract the detected number plate region.
- Process the plate image for better recognition.
- Recognize the characters using OCR.
- Demonstrate the practical application of computer vision and machine learning.

## ⚙️ Working Process

The system follows the following workflow:

**Input Image → Number Plate Detection → ROI Extraction → Image Processing → OCR → Recognized Plate Number**

## 🛠️ Technologies Used

- Python
- OpenCV
- YOLO
- OCR
- Computer Vision
- Image Processing
- Machine Learning

The system successfully detects vehicle number plates from input images and extracts the plate region for character recognition using OCR.
